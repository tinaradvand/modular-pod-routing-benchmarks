# Modular Pod Routing Data and Benchmark Instances

- `static_gtfs_manhattan/`: MTA static GTFS data used for Manhattan bus schedules, trips, stops, and route geometry.
- `realtime_gtfs_raw/`: raw MTA Bus Time real-time data collected in February 2025 and saved as hourly CSV files.
- `trips_with_required_pods/`: scheduled trips with the estimated number of modular pods required to serve them.
- `instances/`: all 134 graph instances created for the modular pod-routing experiments.
- `metadata/`: routes, direction, and size information for every graph instance.
