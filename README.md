# Modular Pod Routing Data and Benchmark Instances

- `manhattan_static_gtfs/`: MTA static GTFS data used for Manhattan bus schedules, trips, stops, and route geometry.
- `manhattan_realtime_gtfs/`: raw MTA Bus Time real-time data collected in February 2025 and saved as hourly CSV files.
- `manhattan_trips_with_pod_requirements/`: scheduled trips with the estimated number of modular pods required to serve them.
- `pod_routing_graph_instances/`: all 134 graph instances created for the modular pod-routing experiments.
- `graph_instance_metadata/`: routes, direction, and size information for every graph instance.
